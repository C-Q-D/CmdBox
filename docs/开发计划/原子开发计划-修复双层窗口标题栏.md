## 总体计划

- 用户结果：真实 Windows/Tauri 窗口只显示一层 CmdBox 自定义标题栏，用户可以从该标题栏拖动、最小化、最大化或还原并关闭窗口。
- 现状证据：真实宿主截图同时显示 Windows 原生标题栏和页面内 `window-bar`；页面内三个图标只是装饰，没有窗口行为。
- 界面继承：保留用户确认的 `editorial-field-notes` 顶栏、品牌标识、尺寸和内容区布局；只修复宿主窗口框架漂移。
- 明确排除：不修改 Command Workspace 内容、导航、执行状态、Typed IPC、Rust Execution Core、窗口尺寸策略或其他命令能力。
- 权限边界：只允许 `main` 窗口执行最小化、切换最大化、关闭、拖动和 Tauri 拖动脚本内部的双击最大化；不开放创建、销毁、定位、改尺寸或操作其他窗口。
- 执行模式：连续执行，一个代码原子完成全部必要配置、控件和真实宿主验证。
- Git 策略：规划和代码原子分别提交；验证通过后立即推送 `master` 到 `origin/master`。
- 整体回归：`pnpm check`；真实 Windows/Tauri 单标题栏、拖动、按钮、双击最大化/还原和 CMD-01 执行回归。
- 计划质疑：L2 隔离审查发现 Tauri 拖动脚本需要独立 `allow-internal-toggle-maximize` 权限，并禁止再实现一套 React 双击处理；修订后其余边界通过。

## BUG-WINDOW-01 让 CmdBox 自定义顶栏成为唯一窗口框架

- 状态：completed
- 支持的验收场景：用户打开真实 CmdBox 后不再看到两层 Windows 标题栏，并能从唯一顶栏完成常用窗口操作。
- 唯一目标：以现有页面 `window-bar` 接管 Tauri 主窗口框架。
- 当前行为与目标行为：当前 Tauri 使用默认原生装饰，页面又绘制一套窗口顶栏；完成后主窗口 `decorations=false`，页面顶栏成为唯一标题栏且三个按钮均执行真实窗口操作。
- 前置条件与依赖：`CMD-01` 已完成；当前 Tauri 2、`@tauri-apps/api` 和已确认视觉语法保持不变。
- 代码定位依据：`src-tauri/tauri.conf.json` 定义主窗口；`src-tauri/capabilities/default.json` 当前无窗口权限；`CommandWorkspace.tsx` 的 `window-bar/window-caption` 绘制装饰图标；`App.css` 定义顶栏视觉；`App.test.tsx` 提供组件测试入口。
- 允许修改：主窗口配置、主窗口 Capability、最小窗口控制网关、`CommandWorkspace` 顶栏标记和按钮、局部 CSS、对应测试、当前计划和必要验收文档。
- 明确不修改：业务 IPC、Execution 生命周期、Output、命令索引、全局导航、品牌令牌和其他窗口。
- 实现步骤：
  1. 把 Tauri `main` 窗口设为无原生装饰，继续保留现有可调整尺寸和最小尺寸。
  2. Capability 精确增加 `allow-minimize`、`allow-toggle-maximize`、`allow-close`、`allow-start-dragging` 和 `allow-internal-toggle-maximize`。
  3. 建立可注入的最小 `DesktopWindowControls`，真实宿主只代理当前窗口的 `minimize`、`toggleMaximize` 和 `close`；浏览器环境返回不可用。
  4. 把三个图标改成有可访问名称、焦点态和悬停态的按钮；标题栏使用 `data-tauri-drag-region="deep"` 覆盖品牌子元素，按钮显式排除拖动属性。
  5. 双击最大化/还原只使用 Tauri drag-region 内建行为，不增加 React `onDoubleClick`。
  6. 在真实 Tauri 宿主检查单标题栏、拖动、三个按钮、双击最大化/还原和既有执行路径。
- 接口、数据与错误契约：窗口控制网关不接受窗口标签、尺寸、位置或任意命令；按钮触发 Promise 失败不得影响 Command Workspace 业务状态。
- 边界与异常：纯浏览器预览中窗口按钮保持可见但禁用；关闭按钮只对应当前主窗口的普通关闭，不使用 `destroy`。
- 测试要求：三个按钮各调用一次对应注入方法；浏览器降级按钮禁用；静态配置断言 `decorations=false` 且 Capability 权限集合精确；原有工作区测试不回归。
- 验证命令：窗口控件定向 Vitest；`pnpm check`；`dev.cmd -Detached` 后真实窗口操作与截图；`stop.cmd` 清理。
- 预期结果：真实 Windows 截图只有一层 CmdBox 顶栏，窗口操作可用，完整回归通过。
- 完成判定：用户报告的双层窗口结构消失，唯一自定义顶栏具备完整基本窗口行为，没有扩大权限或改变业务界面。
- 交付给下一原子的输出：不适用；本计划只有一个原子。
- 停止或重新规划条件：Windows 无装饰窗口无法保持现有 resize 行为，或 Tauri 当前版本的 drag region 与窗口权限契约不符。
- 风险等级：L2
- DDD 门禁：提交前隔离审查窗口权限最小性、浏览器降级、关闭语义和真实宿主证据，必须 `PASS`。
