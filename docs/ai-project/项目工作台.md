## 项目定义

- 核心问题：常用 CLI 命令难以记忆、查找、正确替换参数和安全重复执行。
- 目标用户：Developer、DevOps / SRE、Power User。
- 项目目标：把一次性 CLI 命令封装成可搜索、可参数化、可预览并能安全执行的桌面操作界面。
- 成功结果：用户可以通过 CmdBox 安全、快速地删除多个 Windows 超大文件夹，并能保存和复用其他一次性 Command Block。
- MVP：Windows First；PowerShell/CMD；一次性任务；实时输出；Cancel；历史；Command Block；Hero Delete。
- 明确不做：Interactive Terminal、SSH 长连接、Workflow、云同步、团队、Marketplace、Plugin、Agent、定时任务。
- 核心流程：选择 Command Block → 填写参数 → Preview → Run → 实时输出 → Outcome → History。

详细定义：[产品定义](../product/产品定义.md)
