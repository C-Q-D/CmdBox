CmdBox 采用完整路线。系统范围涉及桌面前端、Rust Native Core、SQLite、外部进程、Windows 文件系统与进程树；永久删除属于不可逆高失败影响操作，Preview 一致性和 Cancel 正确性也难以仅靠局部单元测试证明。
