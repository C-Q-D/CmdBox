## Windows 超大文件夹与文件操作案例

```powershell
foreach ($path in @(

    'E:\comp\nlp2sql\nlp2sql-openclaw\prod\releases\20260805-041753-80d7ee13'
    'E:\comp\nlp2sql\nlp2sql-openclaw\prod\releases\20260806-003724-554407cd'
    'E:\comp\nlp2sql\nlp2sql-openclaw\prod\releases\20260805-045416-f3cf71ae'
    'E:\comp\nlp2sql\nlp2sql-openclaw\prod\releases\20260805-044839-62903fe1'
    'E:\comp\nlp2sql\nlp2sql-openclaw\prod\releases\20260805-044501-f09697a3'
)) {
    Write-Host "正在删除：$path"
    Remove-Item -LiteralPath $path -Recurse -Force -ErrorAction Continue
}
```

压缩成终端单行：

```powershell
@('E:\comp\nlp2sql\nlp2sql-openclaw\prod\releases\20260806-142314-b8a86c0d','E:\comp\nlp2sql\nlp2sql-openclaw\prod\releases\20260805-041753-80d7ee13','E:\comp\nlp2sql\nlp2sql-openclaw\prod\releases\20260806-003724-554407cd','E:\comp\nlp2sql\nlp2sql-openclaw\prod\releases\20260805-045416-f3cf71ae','E:\comp\nlp2sql\nlp2sql-openclaw\prod\releases\20260805-044839-62903fe1','E:\comp\nlp2sql\nlp2sql-openclaw\prod\releases\20260805-044501-f09697a3') | ForEach-Object { Remove-Item -LiteralPath $_ -Recurse -Force }
```

Windows 处理大量小文件原生命令（按 `Win + R` 输入 `cmd` 执行）：

---

### 1. 🚀 最快复制 (Copy)

利用 Robocopy 的多线程并发能力，极速传输小文件：

```cmd
robocopy "D:\源文件夹" "E:\目标文件夹" /E /MT:32 /R:1 /W:1 /NP

```

---

### 2. ⚡ 最快移动 (Move)

* **同盘移动（秒级完成）：**
仅仅修改文件系统索引，无需实际传输数据。
```cmd
move "D:\源文件夹" "D:\目标父文件夹\"

```


* **跨盘移动：**
开启 32 线程并发复制并自动清理源文件。
```cmd
robocopy "D:\源文件夹" "E:\目标文件夹" /E /MOVE /MT:32 /R:1 /W:1 /NP

```



---

### 3. 💥 最快删除 (Delete)

跳过 UI 界的预扫描和回收站，先静音清空文件再删目录：

```cmd
del /f /s /q /a "D:\要删除的文件夹\*.*" && rmdir /s /q "D:\要删除的文件夹"

```

---

### 💡 关键参数说明

* `/MT:32`：开启 32 个线程并发处理（小文件加速的核心，高性能 SSD 可改为 `/MT:64`）。
* `/NP`：不显示每一个文件的进度，减少 CMD 刷屏开销，显著提升执行速度。
* `/R:1 /W:1`：遇到被锁定的文件重试 1 次、等待 1 秒，防止命令卡死。
